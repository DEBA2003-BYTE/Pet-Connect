# PetConnect Frontend

React + Vite + Bun frontend for PetConnect - A unified platform for pet and street animal welfare in India.

## Features

- 🚨 Real-time rescue map with OpenStreetMap
- 🏥 Nearby services locator (vets, clinics, groomers)
- 🐾 Lost & Found pet system
- ❤️ Adoption network
- 👥 Community forum
- 📅 Events & activities
- 🏆 Gamified volunteer system

## Tech Stack

- React 19
- Vite
- React Router
- React Query
- Leaflet + OpenStreetMap
- Axios
- React Hook Form + Zod

## Getting Started

1. Install dependencies:
```bash
bun install
```

2. Start development server:
```bash
bun dev
```

3. Build for production:
```bash
bun run build
```

The app will run on http://localhost:3000

## Environment

The frontend proxies API requests to the backend at http://localhost:5000
